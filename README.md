PROJECT TITLE 
# AMAZON PRIME DATA VIDEO DATA ANALYSIS

PROJECT  DESCRIPTION
This project analyzes  Amazon Prime content data to understand trends in movies and TV shows .This project focuses on performing Exploratory Data Analysis (EDA) on the Amazon Prime Video dataset to extract meaningful insights about content distribution, user ratings, and popularity trends. The analysis includes data cleaning, handling missing values, and transforming data for better usability. Various visualizations have been created using Python libraries such as Pandas, Matplotlib, and Seaborn to identify patterns and trends in the dataset. Key insights include the distribution of movies and TV shows, trends over the years, top-rated content based on IMDb scores, and relationships between important features like popularity, votes, and ratings .Also using the EDA to make dashboard using the Power BI.
The goal is to explore:
- Content distribution
- Popular genres
- Release trends over the years
